System knows the height
The engine solves position on the floor plane, so it converts every 3D range to a horizontal one using the height difference. If the assumed height is wrong the error grows — turn System knows the height off to see it. With ≥4 anchors at different heights LOCUS also estimates your height (shown top-left of the view).

AnchorRSSIRangeTrust
What is real and what is not. The motion of the dot is real (your phone's step counter and compass). The radio signal is synthetic: LOCUS computes the RSSI the anchors would hear from the phone's true position, adds noise, and the engine localises from that. "Truth" is dead-reckoned from the phone, so it drifts over minutes; use short walks, press Align often. Real BLE hardware is the Staff app's Live BLE tab.
